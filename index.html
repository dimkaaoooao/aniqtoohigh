What we are

AnIqTooHigh started as a Discord server with a joke name and a group of friends who refused to use boring group chats. It became something more — a structured creative operation with roles, schedules, project docs, and now an actual game.

We build things in Roblox Studio using Lua, document everything obsessively, and treat every project like it matters. Because it does.

The name comes from a meme. The work doesn't.
